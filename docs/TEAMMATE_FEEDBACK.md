## 4. Математика фильтра

| # | Совет | Вердикт | Факт / действие |
|---|---|---|---|
| 1 | Потолок шага k 0,4 % — причина плохого `defd0170` | частично | копия судьи проверила на train: снятие потолка (`landmark_max_dk=0.015`) **ухудшает**, а расширение априора `init_sigma_scale` 0,006→0,015 лечит: `defd0170` 48 → 1,8 м вдоль пути, дрейф 1,72 → 0,044 %. **▶ берём широкий априор, потолок оставляем** |
| 2 | Кривизна для задней тележки в её точке; уклон, усреднённый по кузову | ▶ | геометрию теперь знаем: передняя тележка +9,9 м от антенны 1, задняя +2,35 м. Правка написана, проверяем на val |

Проверка на val по полю из train: скорость внутри 10-с окон без колёс 0,732 → 0,715 м/с, путь за окно 3,71 → 3,63 м, на чистых данных вдоль пути 2,83 → 2,72 м |
| 4 | Упреждение 45 мс откалибровано по сырому GNSS, а судья — Autoware-слияние | ✖ (оставляем 45 мс) | запаздывают скорости, а не координаты. Колёса считают импульсы за окно ~0,1 с, доплер GNSS усредняет скорость между эпохами 10 Гц. Обе скорости отражают середину окна, то есть на ~45–50 мс раньше своей метки. Отсюда совпадение колёс с доплером (лаг 0) и опережение \|dp/dt\| на 43–44 мс. Координата фикса верна на своей метке. Наш фильтр живёт во «времени колёс», поэтому публикуем s(t + 45 мс). Это нужно против **любого** физически верного эталона, в том числе слитого. Скорость не сдвигаем: эталон скорости у организаторов — те же колёса/доплер |
| 5 | NIS ≈ 1, окрашенный шум колёс | ▶ частично | ковариации пересчитываем по NEES (см. §3). Раздутие R по автокорреляции — после |
| 6 | Пороги CUSUM из теории ARL (Зигмунд) | 📋 | в отчёт: частота ложных тревог по построению + фактическая 0 на val |
| 7 | Ассоциация балис при большой σ_s | ✔ сделано | подтверждено: в `dd8d0741` перепутаны места 3433 и 3439 м, σ_s «схлопнулась». Теперь PDA: смесь всех кандидатов в гейте и гипотезы «не балиса», разброс гипотез добавляется в ковариацию. Val: вдоль пути 2,97 → 2,83 м (среднее), 1,05 → 0,95 м (медиана). Длительность стоянки как признак проверили: слабый (отношение правдоподобий 0,6–1,6), не берём |

## 5. Смелые идеи

| Идея | Вердикт |

| Наблюдаемость k по уклону и переходу «сила → мощность» | ✔ проверено, ✖ на практике: теоретически G_мощн / G_сила = 1 + k. На 52 прогонах оценка k по двум режимам имеет разброс 4,0 % при истинном 0,36 %, корреляция 0,09 (`analysis/k_observability.py`).
