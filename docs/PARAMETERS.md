# Допущения, ограничения и настраиваемые параметры

Все числовые параметры собраны в одном реестре ядра и в файле
`ros2_ws/src/tram_backup_odometry/config/params.yaml`. Файл генерируется из реестра (`tbo_replay --dump-params`),
у каждого параметра в нём — значение, единицы и пояснение. Модульный тест проверяет, что ключи файла и реестра
совпадают. Нода объявляет их параметрами ROS 2. Изменить можно так:

```bash
ros2 launch tram_backup_odometry tram_backup_odometry.launch.py params_file:=/path/to/my_params.yaml
ros2 run tram_backup_odometry tbo_node --ros-args --params-file /path/to/my_params.yaml -p output_frame:=enu
```

Ниже — значения по умолчанию, то есть сдаваемая конфигурация. Модель и механизмы описаны в `docs/MODEL.md`.

## 1. Допущения

1. **Входы.** Скорости передней и задней тележек приходят в км/ч; это подтвердили организаторы, в README опечатка.
   Пересчёт — × 1.00037 / 3.6, поправка 1.00037 откалибрована на прямых участках. Позиция ручки контроллера
   n ∈ [−15, +15]. Время — `header.stamp` входов: часы стенда в расчётах не участвуют.
2. **GNSS** используется только в первые 5 с от первого фикса: привязка к карте и направление, затем нода
   отписывается. Если GNSS нет вовсе, место находится по карте — по остановкам, сбросам тяги и огибающей скорости.
3. **Вагон** — 71-911 «Львёнок». База тележек 7.55 м. TF антенн от организаторов: master на x = −9.873, rover на
   x = +2.563 м, обе на z = +3.0 м в `base_link`.
4. **Маршрут** тот же, что в данных. Карта пути, места остановок и сбросов тяги построены офлайн по GNSS-трекам
   датасета и лежат в пакете (`maps/`); организаторы это разрешили.
5. **Масштаб колеса** k постоянен внутри прогона. Шаг показаний тележки q = c·(1 + k), где c постоянна для вагона
   и эпохи колёс (таблица `maps/wheel_epochs.csv` по нашим записям).
6. **Привод** отрабатывает уставку силы. Характеристики мотора неизвестны, поэтому тяга — выученная таблица
   ускорения a\*(n, v) с инерционным звеном, а не физическая модель мотора.
7. **Эталон судьи** — слитая локализация `/localization/kinematic_state`. На проверочном бэге организаторов она
   запаздывает: скорость — на ~0.1 с относительно колёс, положение — на ~0.08 с относительно RTK.
8. **Выход** — `base_link` (ось передней тележки на уровне головки рельса) в системе карты Autoware MGRS 37U CB;
   z — высота антенн по GNSS минус 3.0 м.
9. **Сбои датчиков** — проскальзывание, юз, залипание, пропуски, выбросы, сбои меток и контроллера — распознаются.
   Полный отказ обеих тележек модель перекрывает до 10 с, дальше точность падает.

## 2. Ограничения

Кратко; подробно, с числами, — `docs/LIMITATIONS.md`:
- без GNSS в начале положение публикуется только после того, как нода найдёт себя на карте: медиана 194 с на val;
- если эпохи колёс вагона нет в таблице, масштаб до первой балисы известен лишь до ±1.5 %;
- выбор параллельного пути на стрелке без GNSS не наблюдаем, кроме тупика у западной конечной;
- точность модели без колёс — 0.7 м/с за 10 с;
- медленные совместные рампы проскальзывания ловятся плохо.

## 3. Параметры по пунктам формы

### 3.1. Начальная позиция

Вручную не задаётся: нода находит её сама.

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `gnss_init_window_s` | 5.0 с | GNSS используется столько после первого фикса, затем отписка |
| `init_source` | `master` | антенна для привязки |
| `gnss_min_fixes` | 3 | фиксов для привязки |
| `map_gate_m`, `map_heading_gate_deg` | 25 м, 60° | допуск расстояния и курса до карты |
| `init_sigma_s`, `init_sigma_s_per_m` | 1.0 м, 0.7 | начальная σ пути: 1 м плюс 0.7 × расстояние фикса от карты |
| `use_baseline_heading` | 1 | направление по двум антеннам |
| `global_loc_enable` | 1 | без GNSS — поиск места по карте (`gl_stops_file`, `gl_cutoffs_file`, `speed_envelope_file`) |
| `nognss_relative` | 0 | 1 — до фикса публиковать относительную одометрию, 0 — не публиковать положение |
| `gnss_wait_s` | 4.0 с | сколько ждать первый фикс в стартовой пачке |
| `init_sigma_v`, `init_sigma_d`, `init_sigma_gain` | 0.3 м/с, 0.10 м/с², 0.08 | начальные σ скорости, возмущения, коэффициента тяги |

### 3.2. Масса

Масса явно не задаётся. Тяга задана таблицей установившегося ускорения a\*(n, v), а масса и загрузка вагона
входят в коэффициент реализации тяги g — это состояние фильтра, оно адаптируется на ходу. У вагона 30618
g ≈ 0.97, у 30639 — 1.07–1.09.

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `traction_file` | `config/traction_lut.csv` | a\*(n, v): 31 позиция × 21 узел скорости 0…20 м/с |
| `drive_tau_s` | 0.452 с | инерционное звено «уставка → ускорение», без чистого запаздывания |
| `gain_min`, `gain_max` | 0.6, 1.6 | пределы g |
| `q_gain` | 2·10⁻⁵ 1/с | случайное блуждание g |
| `kg_brake`, `kg_coast`, `kg_traction` | 8.22, 7.98, 7.36 м/с² | влияние уклона по режимам: g/(1 + ρ), ρ ≈ 0.2 — вращающиеся массы |

### 3.3. Радиус колеса

Радиус не нужен: тележки выдают скорость. Погрешность масштаба колеса от износа и настройки — состояние k.
Его калибруют балисы и шаг квантования скорости тележки.

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `wheel_kmh_to_ms` | 1.00037 / 3.6 | пересчёт км/ч → м/с |
| `init_sigma_scale` | 0.015 | априорная σ k: разброс парка ±1.6 % |
| `q_scale` | 10⁻⁹ 1/с | случайное блуждание k |
| `landmark_max_dk` | 0.004 | наибольший шаг k за одну привязку к балисе |
| `wheel_epochs_file` | `maps/wheel_epochs.csv` | c по вагону и эпохе колёс: k = q / c − 1 |
| `quant_k_enable`, `quant_k_sigma` | 1, 0.0008 | учёт k по шагу квантования и его σ |
| `quant_k_max` | 0.02 | \|k\| больше — неизвестная эпоха колёс, не используется |
| `quant_k_gate_sd`, `quant_k_ambig_sd` | 3, 3 | кандидат — в пределах 3σ от k фильтра, остальные дальше ещё на 3σ |
| `quant_step_lo_kmh`, `quant_step_hi_kmh`, `quant_step_tol_kmh` | 0.0035, 0.0062, 5·10⁻⁵ км/ч | поиск шага показаний |
| `quant_min_steps`, `quant_min_share` | 10, 0.6 | сколько шагов нужно и какая их доля должна совпасть |
| `wheel_curv_abs`, `wheel_curv_signed`, `wheel_curv_sat` | 0.415, −0.054, 0.009 | в кривых колёса недомеряют: 1 + min(a\|κ\|, 0.009) + bκ |
| `front_bogie_along_m`, `rear_bogie_along_m` | 9.873, 2.323 м | где тележки относительно антенны 1: кривизна берётся в месте каждой тележки |
