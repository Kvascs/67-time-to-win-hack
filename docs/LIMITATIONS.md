# Ограничения и план развития

Все числа ниже измерены: валидация на 17 отложенных бэгах (карта, балисы и поле невязки построены только по train),
наборы сбоев — `tools/anomaly_sim`, проверка согласованности — `docs/CONSISTENCY.md`.

## Ограничения

| # | Ограничение | Насколько велико | Что смягчает |
|---|---|---|---|
| 1 | **Нужна привязка по GNSS в первые секунды** (README: GNSS гарантирован в начале проверочных бэгов) | без GNSS нода публикует относительную одометрию от старта, пока нет абсолютной привязки | прототип глобальной привязки без GNSS по остановкам и сбросам тяги: фикс за медиану 176 с / 355 м, 0 ложных на 64 бэгах (`research/global_loc/REPORT.md`); в ядро пока не перенесён |
| 2 | **Масштаб колеса до первой балисы.** Масштаб у разных вагонов и дат различается до ±1,6 %, из колёс и модели он не наблюдаем | до первой остановки у известного места (обычно 150–400 м) путь может уйти на 1–2 % пройденного | априор σ_k = 1,5 %; балисы (49 остановок, 4 места сброса тяги) калибруют k на ходу; после этого дрейф 0,01–0,03 % |
| 3 | **Выбор пути на стрелке не наблюдаем.** Объезд 27.07 (4–5,7 м от главного пути), веерные пути конечной | поперечная ошибка 4–50 м на этих участках: 1,9 % RTK-эпох val, 3,8 % train | ветки в карте используются, если на них стоит старт; иначе — главный путь |
| 4 | **Карта — путь антенны**, а base_link лежит на рельсах | после построения точки по оси кузова остаток в петлях R ≈ 16 м — доли метра | карта рельсовой оси — в плане развития |
| 5 | **Высота z из карты** (GNSS-треки обучающих прогонов) | z RMSE: медиана 0,48 м по бэгам | смещение по z −0,01 м: конвенция высоты совпадает с эталоном (антенна − 3,0 м) |
| 6 | **Точность модели без колёс.** Используется при совместном проскальзывании или юзе и при пропуске обеих тележек | скорость в 10-секундных окнах без колёс: 0,72 м/с RMSE; путь за окно 3,6 м | уклон и поле невязки d(s) в динамике; откат на модельную траекторию; ограничение возмущения |
| 7 | **Медленные совместные рампы проскальзывания** (обе тележки плавно на +10…30 % за секунды) | обнаружение 0–48 %, ошибка скорости до 2,5 м/с (p90) | медленная опора возмущения для CUSUM (τ = 20 с); на реальных данных таких событий не найдено |
| 8 | **Эталонная задержка по меткам.** Время — `header.stamp` входов; в стартовой пачке bag сообщения на 2–6 с старше времени записи | выходы для таких входов несут их (старые) метки | порядок и скачки меток обрабатываются (буфер 0,3 с, подтверждение скачков); задержка «вход → выход» < 1 мс |
| 9 | **Флаг «контроллер не согласован»** даёт ложные срабатывания | 1,8 в час на чистых данных | флаг диагностический, на оценку скорости не влияет |
| 10 | **Живой замер в ROS** (задержка, CPU, RAM под `--cpus=2 --memory=512m`) | офлайн: обработка p99 < 1 мс, частота ~43 Гц | скрипт `scripts/check_run.sh` и Dockerfile готовы; прогон — перед сдачей |

## План развития

| Направление | Что есть сейчас | Следующий шаг |
|---|---|---|
| Работа без GNSS | прототип глобальной привязки (сеточный фильтр по смещению и масштабу, признаки: остановки, проезды мест без остановки, сбросы тяги, огибающая скорости) | порт в ядро по псевдокоду из отчёта; режим `no_gnss_mode` |
| Карта рельсовой оси и карта организаторов | своя карта по GNSS (точность 1 см, медиана) | перестроить по оси тележек; сверить с pathgraph организаторов |
| Калибровка масштаба колёс по данным депо | k по дате и вагону уже виден (`docs/PRODUCTS.md`) | задавать априор k из журнала обточки колёс |
| Карта сцепления как априор сбоев | поддержка в ядре (`fault_prior_file`), таблица по прогонам (`analysis/products/adhesion_map.csv`) | накопить статистику: пока 26 эпизодов на 458 км |
| Контроль целостности | публикуется 99 %-я граница ошибки вдоль пути (PL = 5,76·σ_s, покрытие 0,989 на val) | тревога, если граница больше допустимой для задачи |
| Продукты на тех же оценках | износ/калибровка колёс, жёсткие торможения, профиль скорости, экодрайвинг (`docs/PRODUCTS.md`) | интеграция в диспетчерскую систему |
| Проверено и не взято | связь «уклон → положение» в фильтре, наблюдаемость k по режимам тяги, длительность стоянки как признак, SLAM на линии, скорость по задержке между тележками (`docs/MODEL.md` §8) | — |
