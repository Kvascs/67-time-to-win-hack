## Алгоритм

**Сетка** `G[j,i]`: `i` — место старта u0 в колёсной координате (du = 0,5 м, 22 087 ячеек); `j` — масштаб κ
(51 строка от −2,5 до +2,5 %). Текущее место ячейки при показании одометра r: u = u0 + r/(1+κ). Ячейки не
двигаются; каждый признак — множитель правдоподобия; шум одометра — размытие вдоль u0.

**Признаки:**
- **остановка** (стоянка ≥ 1,5 с): L = 1 + Σ p_m·N(u; u_m, σ²+0,5²)/λ, λ = 1,5 × 0,75 на км;
- **проезд ориентира без остановки**: множитель ∏(1−p_m), p ≤ 0,9, защитная зона 3 м;
- **отсечка** (позиция ≥ 4 → 0 при v > 2 м/с): смесь по 4 местам, σ ≥ 1,5 м, λ_c = 5e-5 1/м;
- **проезд места отсечки** на позиции ≥ 4 без отсечки: множитель (1−q);
- **скорость**: максимум на интервале выше огибающей + 1,5 м/с → множитель 0,05;
- **уклон** реализован (фильтр Калмана смещения в каждой ячейке), но выключен — пользы не дал.

Контрольная точка каждые 50 м. Размытие: q = 0,004 м²/м, скачки ±20 м с частотой 1 на 10 км, пол 1e-9.
**Фикс:** масса в ±10 м от моды ≥ 0,99 и не меньше двух положительных признаков (остановки или отсечки).

## Рекомендация для C++

**Параметры** (`GLParams` по умолчанию): `du` = 0,5; κ = ±2,5 % шаг 0,1 %, априорное СКО κ 1,2 %;
`q_x` = 0,004; `jump_rate` = 1e-4; `jump_hw` = 20; `floor` = 1e-9; `checkpoint` = 50 м; `stop_dwell` = 1,5 с;
`lm_sd_extra` = 0,5; `stop_rate` = 0,75/км × 1,5; `guard` = 3; `p_max` = 0,9; `cut_sd_min` = 1,5;
`cut_rate_min` = 5e-5; `v_margin` = 1,5; `v_eps` = 0,05; `win` = ±10 м; `p_fix` = 0,99; `min_cues` = 2;
`use_grade` = 0; `use_start` = 0 (пока нет проверки стартов с середины маршрута).

**Файлы карты:** пересчитанные p остановок и q отсечек из `cache/calib_train.npz` добавить колонками в
`landmarks.csv` и `cutoffs.csv`; огибающую скорости — отдельным файлом.

**Данные:** `G` — float, nk·nx ≈ 1,13 млн (4,5 МБ); `c_j` = 1/(1+κ_j); периодические таблицы на 3 круга
(`stop_tab`, `cut_tab` с шагом du/10; `pass_cum` — накопленная сумма log(1−p); `v_env`); история позиции
контроллера по одометру, одометры отсечек; счётчики. Всего ~15 МБ. Обновления раз в ≤ 50 м, 1–2 прохода по
1,1 млн ячеек, оценка 2–5 мс в C++ (расчёт, не измерение).

**Псевдокод:**
```
on_committed_step(t,v,standstill,notch):
  r += v*dt
  record notch changes vs r
  standstill >= 1.5 s (not initial)          -> on_stop(r)
  prev_notch >= 4 && notch == 0 && v > 2     -> on_cutoff(r + v*0.045)
  every 50 m                                 -> on_checkpoint(r, vmax)
  after an update: e = estimate(r)
    if !fixed && e.conf >= 0.99 && n_pos >= 2: handover(e)

row shift a_j = r*c_j/du   (cell i is currently at i + a_j)

on_stop:       blur; pass_through(r, -3 m); G[j,i] *= stop_tab[fine slice]; n_pos++; r_pass = r; off = +3 m; normalise
on_cutoff:     G *= cut_tab slice; n_pos++; normalise
on_checkpoint: blur; pass_through; cut_pass; speed envelope mask x0.05; normalise
pass_through:  G[j,i] *= exp(pass_cum[b0+i] - pass_cum[a0+i] + laps*lap)
cut_pass:      for k in (a,b]: i = floor(uc/du - k) mod nx; r_at = k*du/c_j
                 if notch(r_at - 8) >= 4 && no cut-off within 15 m: G[j,i] *= 1 - q
blur:          gaussian with variance q*dr; box mix +-20 m with weight 1e-4*dr; floor
estimate:      H[(i + a_j) mod nx] += G[j,i]; max window mass +-10 m -> conf, s, kappa
```

**Передача в EKF ядра при фиксе:** `anchored` = `map_matched` = true; `s_offset` = s_est − s_core(сейчас);
P(s,s) ≈ 1 м² + дисперсия внутри окна; k = κ̂, P(k,k) = 0,001²; выход в MGRS строится от начала координат карты
(GNSS не нужен); скачок публикуемой позиции при переходе отметить флагом.

**До фикса** — как сейчас: относительная одометрия, флаги NotInitialized|NoMap. Кадр выдачи без GNSS — вопрос к
судье; параметр `no_gnss_mode = relative | absolute_after_fix`.

**Мониторинг после фикса:** сетку можно не останавливать; если масса вокруг позиции EKF < 0,5 на двух остановках
подряд — считать потерей и вернуться в относительный режим.

## Дефект ядра (важен и вне этой задачи)

В `tbo_replay_fix2` одометр `s` при трогании после стоянки откатывается назад: на 69 бэгах 485 шагов назад больше
1 м, всего 810 м; пример — 30618_d4ba7005, 1135 с: минус 16 м при движении вперёд, флаги 0x46000.
Причина: `jointMonitor` ставит `s = mod_s` от снимка `snap_*`, который не обновляется на стоянке (ветка standstill
в `wheelUpdate` выходит раньше монитора). Исправление: в ветке standstill обновлять `snap_*` (при v = 0) и
сбрасывать `onset`. Скорее всего, это бьёт и по режиму с GNSS — проверить eval до и после правки.
