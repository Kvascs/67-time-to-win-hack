# Сопротивление движению, уклон/кривые, сцепление и крип: модели для резервной одометрии трамвая

Исследовательская записка для кейса «Резервная одометрия по модели» (Московский транспорт, хакатон 2026).
Тема: основное сопротивление (Davis / ПТР), сопротивление от уклона и кривых, вращающиеся массы, тормозные силы,
коэффициент сцепления (Curtius–Kniffler, Kother, таблицы для трамвая), кривые «сила крипа — крип» (Polach и др.),
оценка использования сцепления и уклона онлайн без IMU/GNSS.

## 0. TL;DR — что взять в решение

1. **Подвижной состав.** Вагон 30618 — **71-911ЕМ «Львёнок»** (ПК ТС), Москва, Краснопресненское депо, выпуск 05.2021,
   оснащён для беспилотных испытаний ([transphoto](https://transphoto.org/vehicle/531667/?lang=ru)). 30639 — из той же
   номерной серии 306xx, скорее всего тоже 71-911ЕМ (проверить). Ключевые ТТХ ([eltroll2](https://eltroll2.ru/tram/71_911EM.php)):
   4 асинхронных ТЭД × 72 кВт (MLU 2848 K/4), **колесо Ø620 мм новое / Ø580 мм предельный износ**, **передаточное число 6,921**,
   масса тары **≤ 24 т**, Vmax 75 км/ч, ускорение **≥ 1,4 м/с²**, тормоза: электродинамический (служебный),
   **магнитно-рельсовый** (экстренный), электромеханический дисковый (стояночный); колея 1524 мм, обычные колёсные пары
   (не независимые колёса), схема Bo'Bo' — **все 4 оси моторные**, т.е. нет «бегунковой» оси как эталона скорости.
2. **Уравнение движения (рекомендуемая форма):**
   `(m + m_rot)·dv/dt = F_tr(p,v) − F_br(p,v) − m·g·[w0(v) + i(s) + w_r(s)]/1000 + m·d(t)`,
   где `w0, i, w_r` — удельные величины в Н/кН (= ‰ = кгс/т), `d` — медленно меняющееся «возмущение» (ошибки массы/модели,
   ветер), оцениваемое онлайн. `m_rot ≈ 2–2,5 т` (≈ γ = 0,06–0,11) лучше моделировать **как добавочную массу, а не как множитель**,
   т.к. масса пассажиров меняется, а вращающиеся массы — нет.
3. **Основное сопротивление трамвая ≫ ЖД.** Для трамвая (желобчатые рельсы, малые колёса, крутые кривые, грязь) типично
   **3–10 Н/кН** в диапазоне 0–60 км/ч, против ~1–2 Н/кН у вагонов ЖД по ПТР. Идентифицированная модель Tatra T3:
   `F = 0,0147·M + 125,83·v` [Н; M в кг, v в м/с] (C=0) ([Do et al. 2020](https://arxiv.org/abs/2001.10231)).
   Априор для 71-911ЕМ: **A ≈ 3 Н/кН·(m g), B ≈ 60 Н/(м/с), C ≈ 4,3 Н/(м/с)²** (аэродинамика Cd≈0,9, S≈8 м²) →
   w0 ≈ 3,7 / 5,7 / 8,7 Н/кН при 10 / 30 / 50 км/ч. Калибровать по участкам выбега в 122 обучающих бэгах (раздел 3.5).
4. **Уклон доминирует над сопротивлением.** На маршруте из данных (предварительный профиль команды,
   `analysis/traction_id/grade_profile.csv`) уклоны **от −40,6‰ до +35,8‰ (σ≈15‰)** → до ±0,39 м/с², что в 5–10 раз
   больше w0. Уклон **обязан** быть в модели: лучший вариант — **карта «приведённого уклона» i_eq(s) = i(s) + w_r(s)
   вдоль пути**, построенная офлайн из GNSS-высоты и невязок динамики на обучающих бэгах, + онлайн-поправка δd в фильтре.
5. **Кривые.** Для трамвайных путей в РФ норматив СП 98.13330.2018 п. 5.13 прямо задаёт эквивалент сопротивления кривой
   **w_r = 500/R (‰ = Н/кН)**. Радиусы на обычных линиях — до **20 м** (табл. 4 СП) → до **25 Н/кН** (= 0,23 м/с²!).
   Формула Рёкля 500/(R−30) при R<50 м неприменима (сингулярность), ЖД-норма ПТР 700/R завышает для трамвая.
6. **Сцепление для трамвая (РФ, экспертная методика):** сухие чистые рельсы **0,30–0,35** (с песком 0,40–0,45),
   мокрые **0,20** (0,30), влажные замасленные **0,13** (0,20) — так же при тополином пухе/листве/скошенной траве,
   иней **0,15** (0,22), сухой снег **0,10** (0,15). Зависимость от скорости: Curtius–Kniffler `μ = 7,5/(v+44) + 0,161`,
   Kother `μ = 9/(v+42) + 0,116` (v в км/ч).
7. **Потребное сцепление 71-911ЕМ:** полная тяга ≈ 37–38 кН → **μ_потр ≈ 0,16** (пустой); служебное торможение 1,3 м/с² →
   **≈ 0,145**. Значит, **на мокрых+грязных рельсах, листве, снеге боксование/юз ожидаемы**, на сухих — редки.
   Передняя тележка буксует чаще (задние колёса идут по «очищенному» рельсу).
8. **Крип (микропроскальзывание)**: по модели Polach для колеса Ø620 мм при μ_исп = 0,15 крип ≈ **0,25% (сухо)**,
   **≈1,2% (мокро)** → систематическое завышение скорости колёс в тяге / занижение в торможении на 0,2–1,2%;
   **без эталона (GNSS/IMU) микрокрип ненаблюдаем онлайн** — его надо откалибровать офлайн как функцию (позиция контроллера, v).
9. **Детектор юза/боксования** — комбинация: (а) χ²-тест невязки «колесо − модель» с учётом знака режима,
   (б) физический предел ускорения (|a| > ~1,8 м/с² в тяге, > ~3,2 м/с² в торможении), (в) расхождение тележек,
   (г) **односторонние ограничения**: при боксовании `v_true ≤ min(v_f, v_r)`, при юзе `v_true ≥ max(v_f, v_r)`.
   Во время юза/боксования — чистый прогноз модели с параметрами, адаптированными на предыдущих «чистых» участках.
10. **Онлайн-адаптация** (бонус за «adaptive model tuning»): оценивать масштаб ускорения/массу **кусочно-постоянно между
    остановками** (сброс ковариации массы при стоянке с открытием дверей), уклон/возмущение — как случайное блуждание по
    пути (RLS с множественным забыванием, Vahidi et al. 2005, либо расширенный вектор состояния EKF/UKF).

## 2. Уравнение продольной динамики

### 2.1 Общая форма (СИ)

```
ds/dt = v
m_eff · dv/dt = F_k(p, v) − B(p, v) − W0(v) − W_i(s) − W_r(s, v) + ΔF
m_eff = m + m_rot = m·(1+γ)
W0(v) = A + B·v + C·v²                   (Davis; A,B,C в Н, Н·с/м, Н·с²/м²)
W_i   = m·g·sin θ ≈ m·g·i/1000            (i — уклон в ‰, «+» на подъём)
W_r   = m·g·w_r/1000,  w_r ≈ k_r / R      (кривая; см. §5)
```

### 2.2 Форма «удельных сил» (ПТР/тяговые расчёты)

В тяговых расчётах силы относят к весу: `w = W/(m·g)·1000` в **Н/кН** (исторически кгс/т; 1 кгс/т ≈ 1 Н/кН).
Удобное свойство: **удельное сопротивление 1 Н/кН эквивалентно уклону 1‰**, поэтому все «дорожные» члены
складываются в **приведённый уклон** `i_eq(s) = i(s) + w_r(s)`:

```
dv/dt = g/(1+γ) · [ f_k(p,v) − b(p,v) − w0(v) − i_eq(s) ] / 1000
```

Масштаб: 1 Н/кН ↔ a = 9,81·10⁻³/(1+γ) ≈ **0,009 м/с²**; 10‰ ↔ 0,09 м/с²; 40‰ ↔ 0,36 м/с².

### 2.3 Рекомендуемая форма для фильтра (масса неизвестна)

Так как масса пассажиров неизвестна и меняется на остановках, а тяговый/тормозной привод современных трамваев часто
работает с **компенсацией загрузки** (позиция контроллера ≈ запрос ускорения/замедления до предела по силе),
удобно записывать модель в ускорениях:

```
dv/dt = k_a · a_cmd(p, v, t_since_change) − g/(1+γ)·(w0(v) + i_eq(s))/1000 + d
```

* `a_cmd` — офлайн-идентифицированная карта «позиция → ускорение» (с запаздыванием/ограничением рывка),
* `k_a ∈ [0.7; 1.3]` — масштаб (масса/сцепление/износ), оценивается онлайн и **сбрасывается/переоценивается после каждой
  остановки**,
* `d` — медленное возмущение (ошибка карты уклона, ветер, неточность w0), случайное блуждание по пути.

## 3. Основное сопротивление движению w0

### 3.1 Формула Davis и смысл членов

`W0 = A + B·v + C·v²` ([Rochard & Schmid 2000](https://doi.org/10.1243/0954409001531306);
[Rail vehicle resistance](https://en.wikipedia.org/wiki/Rail_vehicle_resistance)):

* **A** — сопротивление качению и трение в буксах (∝ массе); для трамвая — плюс желобчатый рельс, загрязнение, упругие колёса;
* **B** — механические потери, пропорциональные скорости: гребневое трение/извилистое движение, потери в тяговом приводе
  (редуктор, подшипники ТЭД, вентиляция), импульс засасываемого воздуха систем охлаждения/HVAC;
* **C** — аэродинамика `C = ½·ρ·Cd·S`.

### 3.2 Данные именно по трамваям

| Источник | Модель/данные | Комментарий |
|---|---|---|
| [Do, Herman, Hurák 2020 (arXiv:2001.10231)](https://arxiv.org/abs/2001.10231) — Tatra T3, Острава | **F_r = 0,0147·M + 125,83·v** [Н], M в кг, v в м/с; C = 0 | идентифицировано по выбегу (нейтраль), M≈17 т. Литературные ЖД-формулы (Iwnicki, Rochard–Schmid) **не совпали** с измерениями трамвая |
| [Do et al. 2020 V2V (arXiv:2006.02480)](https://arxiv.org/abs/2006.02480) — VarioLF | та же форма F_r, M = 21,2 т, Kt = 2352, r = 0,35 м, 4×90 кВт | модель торможения подтверждена экспериментами |
| [Karatas, TU Darmstadt/Siemens 2020](https://www.etit.tu-darmstadt.de/media/eas/eas_lehre/lv/gds/02_Zugfoerderung.pdf) | коэф. сопротивления качению: **магистральный ЖД 0,002, трамвай 0,005**, трамвай с упругим (обрезиненным) колесом 0,008 | т.е. A ≈ 2–5 Н/кН (без скоростной части) |
| [Sauthoff-Formel](https://de.wikipedia.org/wiki/Sauthoff-Formel) | классика для вагонов ЖД | для трамвая не калибровалась |

Сравнение (m = 30 т): T3-модель даёт 1,5 / 3,9 / 6,3 / 8,6 Н/кН при 0 / 20 / 40 / 60 км/ч.
Для сравнения, типичные ЖД-формулы ПТР вида `w0 = a + b·v + c·v²` (v в км/ч) для моторных вагонов ЭПС дают порядка
1–2,5 Н/кН в том же диапазоне — **в 2–4 раза ниже**, поэтому брать ПТР «как есть» для трамвая нельзя
(в ПТР, кроме того, основное сопротивление рассчитано на загруженность оси 15–25 т и v до 120–160 км/ч;
формулы — эмпирические, из опытов по выбегу: [ru.wiki «Тяговые расчёты»](https://ru.wikipedia.org/wiki/Тяговые_расчёты),
[lokomo.ru](https://lokomo.ru/podvizhnoy-sostav/sily-soprotivleniya-dvizheniyu-podvizhnogo-sostava-8.html)).

### 3.3 Аэродинамика 71-911ЕМ (оценка)

S ≈ 2,5 м × 3,3 м ≈ 8,3 м²; для короткого одиночного вагона с тупым носом Cd ≈ 0,7–1,0 (лоб + донное + трение по 16,5 м)
→ **C ≈ ½·1,2·0,9·8 ≈ 4,3 Н/(м/с)²**. При 50 км/ч это ≈ 0,83 кН (≈2,8 Н/кН при 30 т), при 70 км/ч ≈ 1,6 кН.
Т.е. при v > 40 км/ч аэродинамикой пренебрегать уже нельзя (упрощение C=0 из статьи по T3 годится только до ~40 км/ч).
Встречный ветер 5 м/с меняет аэродинамический член на ±30–60% → это одна из причин держать онлайн-член `d`.

### 3.4 Рекомендуемый априор для 71-911ЕМ

```
A = 3,0 Н/кН · m·g         (диапазон 1,5–5)
B = 60 Н/(м/с)              (диапазон 30–130; в T3 было 125,8 с C=0)
C = 4,3 Н/(м/с)²            (диапазон 3–6)
→ w0(v_kmh) ≈ 3,0 + 0,057·v + 0,00113·v²  [Н/кН] при m = 30 т
   10 км/ч: 3,7;  30 км/ч: 5,7;  50 км/ч: 8,7;  70 км/ч: 12,5 Н/кН
```

Трогание (сопротивление страгиванию): для вагонов ЖД на роликовых подшипниках ПТР даёт `w_тр = 28/(q0 + 7)` кгс/т
(q0 — нагрузка на ось, т) ([ru.wiki](https://ru.wikipedia.org/wiki/Тяговые_расчёты)); для трамвая q0 ≈ 6–9 т →
≈ 1,7–2,2 Н/кН — мало по сравнению с силой тяги, в модели можно учесть как добавку к A при v < 1–2 км/ч или игнорировать.

### 3.5 Как откалибровать w0 по обучающим бэгам (офлайн)

Метод выбега/энергетический метод ([Lukaszewicz 2007](https://doi.org/10.1243/09544097JRRT88)) адаптированный к нашим данным:

1. Отобрать **сегменты выбега**: `position == 0` не менее 3–5 с после смены позиции (дать затухнуть переходному процессу
   тока/момента ≈ 0,3–1 с), v > 1,5 м/с, нет флагов боксования/юза, |v_f − v_r| мал, валидна GNSS-скорость.
2. Ускорение: из GNSS-скорости (master/rover, 10 Гц) и/или из сглаженной скорости колёс (офлайн можно центральные разности
   + Савицкий–Голей, окно ~1 с).
3. Для каждой точки: `y = −(1+γ)·a/g·1000 − i(s)` (уклон из карты высот), регрессия
   `y = A' + B'·v + C'·v² + k_r·κ(s)` (κ = 1/R из осевой линии маршрута). Робастный МНК (Huber), разбиение по вагонам
   30618/30639, валидация на отложенных бэгах.
4. Энергетический вариант (устойчивее к шуму ускорения): между точками s1→s2 выбега
   `(1+γ)·(v2² − v1²)/2 + g·(h2 − h1) = −g/1000·∫ (w0(v) + w_r) ds` → линейная регрессия по (A', B', C', k_r).
5. Масса в удельной форме почти сокращается (остаётся только через γ = m_rot/m) → оценка w0 устойчива к загрузке.
6. Проверить остатки vs температура/сезон/дождь (если есть метаданные по дате бэга) — трамвайное w0 заметно растёт на
   морозе и при грязи/снеге в желобе.

Альтернатива для онлайн-уточнения: UKF с оценкой коэффициентов сопротивления по выбегу
([Real-time train motion parameter estimation using UKF, TR-C 2022](https://www.sciencedirect.com/science/article/pii/S0968090X22002212);
совместная оценка массы и сопротивления — [Mass-adaptive UKF-LSTM, TR-C 2026](https://www.sciencedirect.com/science/article/pii/S0968090X26003475)).

### 3.6 Потери в приводе

* Двухступенчатый цилиндрический редуктор: η ≈ 0,96–0,98; ТЭД + инвертор: 0,90–0,95.
* В тяге: `F_k = η_g·4·T_m·i/r`; в электрическом торможении потери **помогают** торможению: `F_b = 4·T_m·i/(r·η_g)`.
* На выбеге (инвертор снят с управления) асинхронный ТЭД не возбуждён — остаются механические потери (подшипники,
  вентиляция, масло в редукторе). Потери в редукторе на выбеге для трамваев ≈ 10% мощности, передаваемой с оси на вал
  якоря, и не превышают 1–1,5 кВт ([lokomo/тяговые расчёты](https://lokomo.ru/podvizhnoy-sostav/sily-soprotivleniya-dvizheniyu-podvizhnogo-sostava-8.html))

## 4. Сопротивление от уклона

`W_i = m·g·sin θ ≈ m·g·i/1000`, `w_i = i` [Н/кН = ‰] (tanθ ≈ sinθ до ~120‰,

Нормативы для трамвайных путей РФ ([СП 98.13330.2018](https://meganorm.ru/Data2/1/4293733/4293733057.htm)):

|---|---|
| 5.12 | Продольный уклон на подходах к мостам/путепроводам/эстакадам, рампах тоннелей — **до 60‰**; в тоннелях — до 40‰; на подъездных путях депо — до 30‰; на отстойных путях — 2,5‰ |
| 5.13 | Для кривых предельный уклон уменьшается на **i = 500/R** (эквивалент сопротивления кривой) |

| 5.15 | Вертикальные кривые **R ≥ 500 м** (обособленное полотно, при разности > 7‰) |
| 5.19 | Стрелки — на уклонах ≤ 30‰, глухие пересечения ≤ 10‰ |

Следствия для оценки уклона:
* уклон — **кусочно-линейная функция пути** с элементами ≥ 35 м; пространственная «полоса» изменения ~20–50 м;
* максимальная скорость изменения уклона на вертикальной кривой R_v = 500 м: di/ds = 1/R_v = 2‰/м → 60‰ за 30 м;
* на маршруте из данных (предварительный профиль команды, `C:\MosTransHack\analysis\traction_id\grade_profile.csv`,
  ≈5,6 км, 1121 узел по 5 м, поддержка ~100 проходов): h ∈ [148; 177] м, **i ∈ [−40,6; +35,8]‰, σ ≈ 14,7‰**.
  Это ±0,36 м/с² по ускорению → на 10 с прогноза без уклона ошибка скорости до 3,6 м/с. Уклон — **главный** член после
  силы тяги/торможения.

### 5.2 Рекомендация

* **Априор: w_r = 500/R**, коэффициент `k_r` (400–700) уточнять регрессией по выбегу (§3.5);

  κ растёт линейно — это автоматически сглаживает w_r(s);
* объединять в одну карту `i_eq(s) = i(s) + k_r·κ(s)` (приведённый уклон).

### 5.3 Побочный эффект кривых на одометрию (важно для позиции)

* В кривой R колёсная пара с жёсткой осью проскальзывает: разница путей наружного/внутреннего рельса
  `Δ = s_k/R` (для колеи 1524 мм и R = 20 м — **≈ 7,6%** между рельсами, ±3,8% от оси). Датчик на оси/ТЭД измеряет
  «среднюю» скорость, но возможен систематический сдвиг в тесных кривых (зависит от того, где стоит датчик: ось, ТЭД на
  одной стороне и т.п.) — проверить по данным `v_wheel/v_GNSS` vs κ(s).
* Центр кузова (и антенна GNSS, если она между тележками) идёт по хорде: радиус его траектории
  `R_c = sqrt(R² − (L/2)²)`, где L — база вагона (расстояние между шкворнями). При R = 20 м и L ≈ 9 м путь кузова
  **на ~2,6% короче**, а поперечное смещение от оси пути ≈ 0,5 м. Для эталонной GNSS-траектории это даёт
  систематическую разницу «путь по колёсам ≠ путь антенны» в кривых — учитывать при привязке к карте.

## 7. Тормозные силы

### 7.1 Состав тормозной системы 71-911ЕМ и типовые замедления

* **ЭДТ (рекуперативно-реостатный)** — служебное торможение; сила ограничена моментом ТЭД и мощностью; **затухает при
  малых скоростях** (обычно < 3–7 км/ч) и замещается механическим тормозом (blending) → ступенька/переход в
  замедлении около остановки;
* **механический (дисковый на валу ТЭД/электромеханический)** — дотормаживание и стоянка;
* **магнитно-рельсовый тормоз (МРТ)** — экстренное торможение; сила трения башмака о рельс **не зависит от сцепления
  колесо–рельс** (притяжение 40–80 кН на магнит, μ башмака падает со скоростью), башмаки очищают рельс и повышают
  сцепление последующих колёс ([Track brake](https://en.wikipedia.org/wiki/Track_brake)).

### 7.2 Модель для фильтра

```
F_b(p<0, v) = min( k_b·|p|/15 · F_b,max ,  P_ed/v ) · blend_ED(v) + F_mech(v) · (1 − blend_ED(v)) [+ F_MRT при экстренном]
blend_ED(v) ≈ clip((v − v1)/(v2 − v1), 0, 1),  v1 ≈ 1 м/с, v2 ≈ 2 м/с (калибровать)
dF/dt: первый порядок τ ≈ 0,2–0,4 с (ЭДТ) / 0,5–1,0 с (механика); ограничение рывка ~1–1,5 м/с³
```

* Для T3 идентифицирована инерционность момента `T(t) = (1 − e^{−3t})·T̃(p)` (τ ≈ 0,33 с) и линейная связь момента с
  позицией: тяга `1449·p` Н·м (до ограничения мощностью `P_max/ω`), торможение `1176·p` Н·м, 7+7 позиций
  ([Do 2020](https://arxiv.org/abs/2001.10231)). У 71-911ЕМ 15+15 позиций — ожидаем похожую структуру «позиция → доля
  максимальной силы/ускорения» с ограничением мощностью и рывком.
* Если привод компенсирует загрузку (типично для современных трамваев с датчиками давления в подвешивании), то
  «позиция → замедление» почти не зависит от массы — проверить по разбросу a(p) между бэгами.
* Крайняя тормозная позиция может включать МРТ + песок: там замедление может превышать μ·g и **не ограничено
  сцеплением** → при экстренном торможении колёса могут идти юзом при фактическом замедлении 2,5–3 м/с².

## 8. Сцепление колесо–рельс

### 8.1 Определения

* Коэффициент сцепления (adhesion coefficient) `μ = F_x/Q` — отношение касательной силы к нормальной нагрузке;
  максимум этого отношения — **располагаемое сцепление μ_max**; отношение реализуемой силы к весу — **использование
  сцепления μ_исп (adhesion utilisation)**.
* Скорость проскальзывания `w = ω·r − v`, относительный крип `s = (ω·r − v)/v` (в тяге > 0, в торможении < 0).
* Область крипа (линейная + нелинейная, **устойчивая**) — до ~1–3% (≈ до 2 км/ч скорости скольжения,
  [Pichlík & Zděnek 2014](https://ojs.cvut.cz/ojs/index.php/TEE/article/download/6465/5585/0)); за максимумом —
  неустойчивая зона: боксование (тяга) / юз (торможение).
* По ЖД-литературе: зона a (0–0,8%) — рост пропорционально упругим деформациям, зона b (0,8–2%) — критическая,
  максимум при ~1–1,2%, зона c (>2%) — резкое падение
  ([lokomo.ru](https://lokomo.ru/podvizhnoy-sostav/sila-tyagi-i-tyagovye-harakteristiki-lokomotivov-4.html)).

Выводы: (1) при нормальных условиях крип в тяге/торможении — **0,1–1,2%** скорости (систематическое смещение
показаний колёсной скорости); (2) при «листве/масле» полная тяга (μ_потр ≈ 0,15–0,16) **гарантированно** выводит в
боксование; (3) Polach-сухие параметры дают μ_max ≈ 0,4 — выше «трамвайной» таблицы (0,30–0,35), т.е. для трамвая
разумно масштабировать μ0 (≈0,45) под табл. 8.2.

### 8.5 Упрощённые формы (для реального времени)

* **Экспоненциальная (Takaoka & Kawamura 2000, применена для T3/VarioLF):**
  `μ(w) = c·e^{−a·w} − d·e^{−b·w}` (w — скорость скольжения, м/с); сухо [a,b,c,d] = [0,54; 1,2; 1; 1] → μ_max = 0,286
  при w = 1,21 м/с; «слегка мокро» [0,54; 1,2; 0,2; 0,2] → μ_max = 0,057; мокро [0,05; 0,5; 0,08; 0,08] → μ_max = 0,056
  при w = 5,1 м/с ([Do 2020](https://arxiv.org/abs/2001.10231), [Do V2V 2020](https://arxiv.org/abs/2006.02480),
  [Takaoka & Kawamura](https://doi.org/10.1109/AMC.2000.862851)). Грубо описывает зону крипа (слишком большой крип при
  малых μ) — годится только как «форма» для симуляции юза, не для коррекции крипа.
* **Параметрическая «пиковая»:** `μ(s) = μ_max · 2·s·s*/(s² + s*²)` (s* ≈ 1–3% сухо, 3–10% мокро) — одна кривая с двумя
  параметрами, удобна для онлайн-подстройки μ_max.

### 8.6 Эффект очистки рельса и распределение по тележкам

* Ведущая (передняя по ходу) колёсная пара встречает наихудшее сцепление; последующие оси идут по рельсу, очищенному/
  подогретому предыдущими → **сцепление растёт от передней оси к задней**; это подтверждается данными противобоксовочной
  системы эксплуатационных поездов: длительность боксований в дождь уменьшается от головных вагонов к хвостовым
  ([Tribology Int. 2026](https://www.sciencedirect.com/science/article/abs/pii/S0301679X2600366X)).
  Для 71-911ЕМ (одноголовый, движется всегда кабиной вперёд) → **передняя тележка боксует/юзит чаще**; в фильтре
  априорно больше доверять задней тележке в тяге/торможении на низком сцеплении.
* МРТ и песок увеличивают сцепление последующих колёс.
* В кривых располагаемое сцепление снижается (ЖД-поправка ПТР при R < 500 м).

## 9. Онлайн-оценка: использование сцепления, крип, юз/боксование, уклон

### 9.1 Что наблюдаемо с нашими датчиками

* Есть: скорости передней и задней тележки (10 Гц, неотрицательные), позиция контроллера (20 Гц).
* Нет: момента/тока ТЭД, IMU, «бегунковой» оси, GNSS (кроме первых секунд).
* Следствие: **микрокрип 0,1–1% ненаблюдаем онлайн** (нет эталона); наблюдаемо только **макропроскальзывание** — через
  несоответствие динамике (модель), физическим пределам ускорения и расхождение тележек. Микрокрип и масштаб радиуса
  колеса калибруются **офлайн** по GNSS обучающих бэгов.

### 9.2 Использование сцепления (диагностика, бонусные баллы)

```
μ_исп(t) = (1+γ)·â(t)/g + (w0(v̂) + i_eq(ŝ))/1000          # по оценке фильтра (не по колесу!)
λ_j(t)   = (v_j − v̂)/max(v̂, 1 м/с),  j ∈ {front, rear}     # оценка продольного проскальзывания тележки
μ̂_max   ← при каждом обнаруженном начале боксования/юза: μ_исп(t_onset);
           между событиями: нижняя граница = max μ_исп на «чистых» участках (с экспоненциальным забыванием)
класс условий: dry/wet/low по μ̂_max (пороги ~0,22 и ~0,12) + частоте событий на км
```

Публиковать в `diagnostic_msgs/DiagnosticArray` (или отдельный топик): флаги slip/slide по каждой тележке, λ_j, μ_исп,
μ̂_max, класс условий, «доверие к одометрии». Это прямо закрывает бонус «флаг проскальзывания / оценка коэффициента
сцепления / продольного проскальзывания».

### 9.3 Детектор боксования/юза (практический набор правил)

Для каждой тележки j на каждом измерении:

1. **Невязка модели**: `r_j = v_j − (1+κ_j)·v̂⁻`, нормированная `ν_j² = r_j²/S_j`. Подозрение, если
   `ν_j² > χ²₁(0,999) ≈ 10,8` **и** знак согласован с режимом (тяга: r_j > 0; торможение: r_j < 0).
   Для «медленных» уходов — CUSUM по r_j.
2. **Физический предел ускорения** (фильтр 0,2–0,3 с): тяга `dv_j/dt > a_max_tr ≈ 1,4 + g·i_max/1000 + запас ≈ 1,8–2,0 м/с²`;
   торможение `dv_j/dt < −(2,9…3,2) м/с²`; рывок `|d²v_j/dt²| > 5–10 м/с³`.
3. **Расхождение тележек** (после калибровки масштабов): `|v_f − v_r| > max(0,3 м/с; 3%·v)` → буксует та, что
   дальше от модели (в тяге — более быстрая, в торможении — более медленная).
4. **Синхронное боксование обеих тележек** (все оси моторные!): обе невязки одного знака + высокая позиция контроллера →
   только модель + ограничения п. 5. Аналогичная задача «synchronous slide/slip» решается в тормозных системах через
   опорное замедление ([arXiv:2005.06845](https://arxiv.org/abs/2005.06845) — пороги по разности скоростей осей и
   ускорению в тяге/торможении).
5. **Односторонние ограничения** (физика, очень сильный приём):
   тяга + боксование: `v_true ≤ min(v_f, v_r)`; торможение + юз: `v_true ≥ max(v_f, v_r)` (колёса крутятся медленнее
   кузова). Реализация — проекция оценки на допустимое множество (constrained KF) или «полуизмерение».
6. **Во время события**: R_j ← ×10³ (или пропуск), `k_a`, `d`, масса — **заморожены**; прогноз по модели.
7. **Восстановление (re-adhesion)**: |r_j| < порога в течение 0,5–1 с → R_j возвращать постепенно (экспоненциально за ~1 с),
   чтобы избежать скачка оценки. Встроенная противобоксовочная/противоюзная защита трамвая обычно сама снимает момент
   за доли секунды, поэтому типичные события короткие (0,3–3 с); при экстренном торможении с МРТ юз может быть длительным.
8. **Пропуски/выбросы**: если датчик молчит > 0,3 с — только модель + вторая тележка; значения < 0, NaN, скачки
   > 3 м/с за 0,1 с — отбрасывать.
9. **Остановка (ZUPT)**: обе скорости = 0 ≥ 0,5–1 с и p ≤ 0 → v̂ = 0, P_v → малая; это обнуляет дрейф модели.

Литература по оценке сцепления моделью: фильтр Калмана–Бьюси для крип-сил + постобработка
([Ward, Goodall, Dixon, Charles 2012, VSD 50(12)](https://doi.org/10.1080/00423114.2012.707782)); банк фильтров Калмана
на рабочих точках + нечёткая классификация условий контакта
([Hussain, Mei, Ritchings 2013, VSD 51(1)](https://doi.org/10.1080/00423114.2012.708759)); UKF для противобоксовки
([Pichlík & Zděnek 2018, IEEE TVT](https://doi.org/10.1109/TVT.2018.2808379)); обзор методов противобоксовки
([Pichlík & Zděnek 2014](https://ojs.cvut.cz/ojs/index.php/TEE/article/download/6465/5585/0)); наблюдатель
возмущения для сцепления ([Takaoka & Kawamura 2000](https://doi.org/10.1109/AMC.2000.862851)). В этих работах есть
датчики момента/ускорения; у нас их нет, поэтому для нас применима идея **банка моделей (IMM) по классам сцепления**
лишь в виде априора для порогов детектора и доверия к одометрии.

### 9.4 Оценка уклона без IMU

**(A) Карта приведённого уклона вдоль пути (главный источник, офлайн):**
1. Построить осевую линию маршрута (граф путей) из GNSS обучающих бэгов; параметр — длина дуги s.
2. Высота h(s): медиана/робастное сглаживание по всем проходам (у команды уже ~100 проходов на узел) → i(s) = dh/ds
   с пространственным сглаживанием ~20–50 м (элементы профиля ≥ 35 м по СП 98).
3. Кривизна κ(s) → w_r(s) = k_r·κ(s)·1000 (k_r ≈ 0,5 по СП 98).
4. **Динамическая доводка**: на «чистых» участках выбега/постоянной позиции считать невязку
   `e(s) = a_GNSS − a_model(p, v; i_eq=0)` и усреднять по проходам в бинах по s → `i_eq_dyn(s) = −(1+γ)·e(s)/g·1000 − w0`.
   Сравнить с i(s)+w_r(s) из геометрии; финальная карта — взвешенная комбинация (геометрия лучше в мелком масштабе,
   динамика — несмещённая «эффективная» величина, включающая неучтённые эффекты, например стрелки).
5. Хранить как таблицу (s, i_eq, σ) в пакете (данные не требуют интернета при сборке).

**(B) Онлайн-возмущение в фильтре (поправка к карте):**
```
x = [s, v, d, k_a, (κ_f, κ_r)]
v̇ = k_a·a_cmd(p,v) − g/(1+γ)·(w0(v) + i_eq_map(s))/1000 + d
ḋ = η_d,  Var(η_d·Δt) = q_d·|v|·Δt   (случайное блуждание ПО ПУТИ, q_d ~ (0,01–0,03 м/с²)²/м)
k̇_a = η_k (очень малый q; сброс ковариации при каждой стоянке > 5 с)
```
Уклон/возмущение наблюдаемо только при достоверной скорости колёс (нет юза) и v > ~1 м/с; при юзе/остановке — заморозить.
На стоянке уклон ненаблюдаем (тормоз удерживает вагон).

**(C) RLS с множественным забыванием** ([Vahidi, Stefanopoulou, Peng 2005, VSD 43(1)](https://websites.umich.edu/~annastef/papers_Long_ctrl/JournalPaperMassGrade_Final.pdf)):
регрессия `y = φᵀθ`, `y = v̇`, `φ = [F_model(p,v) − W0(v); −g]`, `θ = [1/m; sin(θ + β)]`; две разные скорости забывания —
масса почти постоянна (λ₁ ≈ 0,999–1,0), уклон меняется (λ₂ ≈ 0,95–0,98 при 10 Гц, лучше — пересчитывать по пройденному
пути). Предупреждения авторов: «раздувание» ковариации (wind-up) при слабом возбуждении (стоянка, постоянная скорость) →
ограничивать P сверху, выключать обновление при |φ| малом/юзе; оценка массы в пределах 5% требует
постоянного возбуждения. Для нас удобнее вариант (B) (EKF), а RLS — как независимый оценщик k_a для контроля.

**(D) Комбинация (рекомендуется):** `i_eq(s) = i_eq_map(s) + δ(s)`, δ — медленная поправка из (B). Если позиция ŝ
дрейфует, карта «съезжает» — ошибка ограничена, т.к. уклон гладкий; дополнительно привязывать ŝ к карте по характерным
событиям (остановки на известных платформах, повороты), это уже задача позиционирования.

### 9.5 Адаптация модели (бонус «adaptive model tuning»)

* `k_a` (масса/эффективность тяги) — оценивать на участках разгона/торможения без юза; **масса кусочно-постоянна между
  остановками** → сбрасывать/раздувать ковариацию `k_a` после каждой стоянки с v=0 > 5–10 с.
* Отдельные масштабы для тяги и торможения (`k_a,tr`, `k_a,br`) — у них разные механизмы и компенсация загрузки.
* Масштабы радиусов колёс `κ_f, κ_r`: офлайн по вагону (30618/30639) из GNSS; онлайн — очень медленный дрейф (или только
  по GNSS первых секунд теста, если скорость там ненулевая).
* Коррекция систематического крипа: `v_true ≈ v_wheel·(1 − s_bias(p, v))`, s_bias ≈ 0,1–1% из офлайн-регрессии
  `v_wheel/v_GNSS − 1` по позиции контроллера (и сезону/условиям, если различимо).

## 11. Подводные камни

1. **Единицы скорости.** В бэгах значения 0…53 при декларированных «м/с» — это похоже на **км/ч** (Vmax 75 км/ч,
   типичная городская скорость ≤ 50–55 км/ч). Проверить сравнением с GNSS-скоростью до любой калибровки.
2. **ЖД-формулы ПТР занижают w0 трамвая в 2–4 раза**; формула Рёкля неприменима при R < ~50 м (сингулярна при R = 30 м),
   ПТР 700/R завышает для трамвая; брать СП 98: 500/R.
3. **Уклон важнее сопротивления**: ±40‰ ≈ ±0,36 м/с² против w0 ≈ 0,03–0,1 м/с². Модель без уклона даст большие ошибки при
   прогнозе в юзе/боксовании и пропусках.
4. **Масса неизвестна и меняется на каждой остановке** (±40% от тары). Любая модель «позиция → сила» требует массы, модель
   «позиция → ускорение» — нет (если есть компенсация загрузки). Проверить, какая гипотеза лучше объясняет данные.
5. **Все оси моторные** → при синхронном боксовании обеих тележек нет эталона: только модель + односторонние ограничения.
6. **Износ колёс** 620 → 580 мм (−6,5%) → масштабная ошибка одометрии до ±3,3% от номинала: **калибровать масштаб по
   каждому вагону** (у 30618 103 бэга, у 30639 — 19), возможно — по периодам (обточка колёс).
7. **Систематический крип** 0,1–1,2% (знак зависит от режима) → смещение скорости в разгонах/торможениях = прямой удар по
   критерию «bias в переходных режимах». Калибруется офлайн.
8. **Тесные кривые**: проскальзывание жёсткой колёсной пары, разница путей тележек и кузова/антенны (до 2–3% при R = 20 м),
   поперечное смещение кузова ~0,5 м — не путать с ошибкой одометрии при сравнении с GNSS-эталоном.
9. **Микрокрип ненаблюдаем онлайн** — не пытаться «оценивать сцепление» по малым невязкам, это будет шум; μ̂_max
   оценивается только по событиям макропроскальзывания.
10. **Экстренное торможение с МРТ** не ограничено сцеплением: фактическое замедление может превышать μ·g, а колёса
    при этом идут юзом → модель торможения должна знать, что крайние тормозные позиции = МРТ.
11. **ЭДТ затухает на малой скорости** (переход на механику) — в последние 1–2 м/с перед остановкой модель торможения
    меняется; плюс «откат» (кузов качается на тележках при остановке — видно в данных T3).
12. **RLS/EKF wind-up** при слабом возбуждении (стоянки, крейсерский режим) — ограничивать ковариацию, замораживать
    адаптацию при юзе и при v ≈ 0.
13. **Смещение карты уклона при дрейфе позиции** → использовать сглаженную карту и привязку ŝ по событиям.
14. **Неотрицательная скорость** датчиков: реверс (маневры в депо) неразличим; ограничить v̂ ≥ 0 и не интегрировать
    назад.
15. **Температура/сезон**: w0 трамвая растёт на морозе (загустевшая смазка, снег в желобе), сцепление зимой/осенью ниже —
    если дата бэга доступна, держать сезонные априоры.
