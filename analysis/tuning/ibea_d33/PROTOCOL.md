# Протокол выбора точки IBEA (записан 27.09 в 21:00, до просмотра отложенных данных)

Критерии для выбора — по бэгам train, нормированные на ручные значения по каждому бэгу (e_b(θ)/e_b(θ0)):
медиана отношения RMSE вдоль пути, хвост — p90 того же отношения, скорость — медиана отношения RMSE скорости.

1. Кандидат: среди недоминируемых точек журнала (все оценки) с отношением скорости ≤ 1.00 и хвостом ≤ 1.00 —
   точка с наименьшей медианой. Если медиана не лучше 0.99 — оставляем ручные значения.
2. Проверка на обрыв: каждый из 7 параметров ±10 % (14 оценок на train). Если хоть одна даёт медиану отношения
   хуже 1.05 или хвост хуже 1.10 — точка у обрыва, берём следующую по правилу 1.
3. Отложенные данные — только для одного финалиста: val (17 бэгов, карты только по train, эталон base_link),
   бэг организаторов их метрикой (офлайн-повтор), набор сбоев (343 прогона).
4. Берём, только если одновременно: на val медиана парного отношения 3-D < 1 и лучше не меньше чем на 2/3 бэгов
   с RTK; на бэге организаторов 3-D не хуже; скорость на val не хуже 1 %; в наборе сбоев разошедшихся ≤ 9 и
   ложных тревог не больше.
5. В отчёт в любом случае: фронт, точка ручных значений на нём, итог проверки.
